# Dependencies for Google Colab and other hosted notebooks.
#
#   pip install -r requirements-colab.txt
#
# PyTorch is deliberately absent: Colab ships a CUDA build matched to its
# runtime, and installing the CUDA 11.6 wheels pinned in requirements.txt would
# replace it with one that does not work there. Everything below is either
# already present in the Colab image (pip then leaves it alone) or a small pure
# Python package.
#
# PyTorch3D and chumpy are intentionally not listed. PyTorch3D has no wheels for
# the Colab Python/CUDA pair and takes tens of minutes to build, and chumpy 0.70
# imports on neither Python 3.11+ nor NumPy 2. The compat/ package replaces both
# with pure PyTorch rotation conversions and a chumpy-free SMPL loader.
